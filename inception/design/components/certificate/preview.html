Certificate

The document a learner opens from their learning history (SCR-008, ST-27) after a session is marked complete. It carries the four facts REQ-024 names and nothing else, in a tab of its own with no application chrome around it. Every example below is one browser tab; the frame is drawn here only to separate them on this page.

Print is absent rather than disabled: there is nothing to print. Same reasoning and nearly the same words as SCR-008's ST-28, which is the state the learner would have seen a moment earlier — one failure should not describe itself two different ways on two screens.

ST-06 — not available to you

← My learning
⚠️

We can't show you this certificate

It may not exist, or it may not be yours.

Go to My learning

No retry — retrying changes neither answer. This follows the same-message-either-way pattern SCR-002 already set for password reset, so the portal has one philosophy about this rather than two. The cost: a learner who mistyped their own URL gets a vaguer message than we could have given them.

Typically a bookmarked URL opened days later — the price of the stable URL that makes the certificate worth having. The toolbar keeps no "My learning" link here, because that destination would bounce off the same sign-in.
