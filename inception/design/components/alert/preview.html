Alert

Every variant pairs an icon with text — colour alone never carries the meaning.

Error — invalid credentials

⚠ Incorrect email or password.

Error — request failed (login, and request a reset)

⚠ Something went wrong. Please try again.

Error — saving a new password failed

⚠ Something went wrong. Your password has not been changed. Please try again.

Warning

⚠ This booking request expires soon.

Success

✓ Session confirmed.

Success — password changed, shown on the login screen

✓ Your password has been changed. Please sign in.

Info

ℹ You've been signed out.

Panels

Used where the alert is the screen rather than an annotation on a form — the reset flow's confirmation and its dead-link explanations.

Panel — reset link requested

✓ Check your email If jane.doe@company.com belongs to a portal account, we've sent a link to reset the password. The link expires in 60 minutes and can be used once. Didn't arrive? Check the address above, then send it again.

Panel — link sent again (polite, not assertive: a repeat)

✓ Sent again — check your email We've sent another link to jane.doe@company.com. Only the newest link will work. You can send again in 47 seconds.

Panel — reset link no longer valid

⚠ This link is no longer valid Password reset links expire 60 minutes after they're sent, and can only be used once. Request a new one to continue.

Panel — reset link already used

⚠ This link has already been used The password for this account was already changed using this link. If that wasn't you, contact IT straight away.

Panel — the trainer list couldn't load

⚠ We couldn't load the list of trainers This is usually a connection problem, not a problem with your account. Try again

Retry is offered because retrying can genuinely work here — the opposite of the expired-link panel above, where nothing about the link will start working. Saying "usually a connection problem" heads off the reasonable guess that the portal has locked them out.

Panel — the teaching page couldn't load

⚠ We couldn't load your teaching page Your published times and any requests waiting on you are safe. Try again

The reassurance is specific: a trainer who cannot see their requests will wonder whether someone's request was lost. Saying nothing was is worth a line. The header above stays usable, so nobody is trapped.

Panel — the learning page couldn't load

⚠ We couldn't load your learning page Your sessions, requests and certificates are all safe. Try again

A learner who cannot see their sessions will wonder whether a booking vanished, and one who cannot see Finished will wonder about a certificate (REQ-024). Naming both costs a clause and answers the question they were about to ask.
