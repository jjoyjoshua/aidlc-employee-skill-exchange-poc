Skills section

The skills half of SCR-005 — two cards, one per list (REQ-009, REQ-010, REQ-011). Two cards rather than one list with a Teach/Learn toggle, because the two carry different consequences: listing something to teach makes the employee findable and bookable with no approval step (REQ-013, BR-001.1), and listing something to learn does not. Chips are the existing skill-chip in its removable form.

Skills I'm learning (1)

◆ Python Beginner

Edit and Remove are real buttons on every chip, not hover affordances, so both are reachable by keyboard and on a touch screen. Each has an accessible name that includes the skill and the list — "Remove" alone tells a screen-reader user nothing about which of six chips they are on. Long catalog names wrap instead of truncating; the catalog is IT-maintained, so the length is not ours to control. The standing line under the teach card is there whenever that list has an entry, because that is what makes the employee publicly findable.

A panel, not a wizard. There are four optional fields and one list, and a wizard would imply a required order and a finish line that no requirement establishes. The profile card sits between the panel and these two cards with all four fields empty — see the profile-form preview.
