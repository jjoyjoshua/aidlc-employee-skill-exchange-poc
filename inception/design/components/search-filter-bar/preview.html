Search and filter bar

The controls above the results on "Find a trainer" (SCR-006): a search box over skill names, and three filters — department, proficiency level, and rating (REQ-012). Everything applies instantly; there is no Apply button, so the count line below is continuous feedback.

The placeholder says "a skill", not "a skill or a name" — REQ-012 defines filtering by skill name, and matching people's names would be a capability nobody has asked for. Raised as OQ-S2 on the screen spec rather than quietly added here.

Department menu open — multi-select

Departments come from the fixed list IT maintains (REQ-008) — this menu never invents one. Each option shows how many colleagues it would leave, so a learner can see a dead end before choosing it; an option that would leave none is disabled rather than hidden, because a department disappearing from the list is more confusing than a department that is visibly empty.

Level menu open — and the sentence that says what "level" means here

You haven't searched a skill, so this matches colleagues at this level in any skill they teach.

The same control answers two different questions depending on whether a skill is searched — "expert in anything" versus "expert in Excel". Saying which reading is in force is the difference between a filter people trust and one they stop using. With a skill searched, the line reads "matches their level in Excel".

Rating menu open — single-select, and the unrated question

Thresholds are a working default (OQ-S6, the designer's call at review). What this filter does to colleagues who have no rating yet is not a design choice — it is the open conflict C-1 between REQ-012 and REQ-013, and the BA owns it. The count line below shows the working default.

Each button carries its own value, so the state of the search is readable without opening anything, and "Clear all" appears only once there is something to clear. The count line is the screen's single aria-live region: one announcement per refinement, rather than a screen reader re-reading the result list. The second sentence is the working default for conflict C-1 — the reveal is one click, never a silent exclusion.
