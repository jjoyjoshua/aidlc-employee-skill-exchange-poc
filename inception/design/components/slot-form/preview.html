Add a time form

How a trainer publishes a bookable time on SCR-007 (REQ-014). Four fields and nothing else: the skill, the day, the hour, the length. A dialog rather than an inline row, because it carries a validation story of its own and would otherwise push the whole availability list down every time it opened.

The form

Add a time

Only skills you've listed as teachable appear here.

Focus lands on Skill and is trapped in the dialog until it closes; Escape cancels without saving and returns focus to the Add a time button. Publish enables only when all four fields hold a value.

⚠ You already have a time at 14:00 that day. A session is one-on-one, so times can't overlap.

The overlap message names the time already published, so the trainer knows which one to look at. Whether overlaps should be blocked at all is a rule nobody has stated — raised as OQ-T4, with blocking as the working default. Everything typed stays put; nothing is cleared by a rejection.
